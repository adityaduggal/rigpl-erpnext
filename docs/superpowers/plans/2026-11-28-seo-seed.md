# SEO Seed Records Implementation Plan (#263, part of #262)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan.

**Goal:** Python defines the Schema Templates and SEO Rules. Each business value links to a database record.

**Spec:** `docs/superpowers/specs/2026-11-28-website-seo-schema-design.md` (D5, §5.1, §6). The user approved the design on 2026-11-28.

## Global Constraints

- No fixtures. Create a record only if no record has its name. Never change a record that exists. SEO Settings: fill an empty field only.
- No `Constant` property row in the seed. Only schema.org names and template words are fixed text.
- Only `website_rigpl/seo/` reads ERPNext field paths (#277).
- A failed seed rolls back, logs the error and does not stop `migrate`.
- A private file is never a public logo.

## Sources

| Value | Source |
|---|---|
| Company | SEO Settings `company`, else Global Defaults `default_company` |
| Legal name, email, phone, founding date | Company |
| Address | SEO Settings `address`, else the company address of the Company, primary first |
| Country code | Country `code` |
| Brand | Website Settings `title_prefix`, else the company name |
| Logo | Website Settings `banner_image` |
| `sameAs` | Website Settings footer links under SEO Settings `social_group` (default `Social`), without WhatsApp links |

## Tasks

1. `seo/organization.py`: `get_organization() -> dict` with all keys always present. `context.build_variables` gives `site.brand` and `site.organization`. SEO Settings gets `company`, `address`, `social_group`; `site_name` is a Jinja text.
2. `website_data/seo/records.py`: `SCHEMA_TEMPLATES`, `SEO_RULES`, `SETTINGS`.
3. `website_data/seo/importer.py`: `create_missing_records() -> List[str]`, `seed_seo_once()` in `after_migrate`. A seeded Schema Template skips the sample route render.
4. SEO Settings: whitelisted `create_records` (write permission) and the form buttons.
5. Guides. Tests in `tests/test_seo_seed.py`.
