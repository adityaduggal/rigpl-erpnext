# SEO Rule Implementation Plan (#261)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The title, description, canonical, robots, `og:*` and `twitter:*` tags of each page type come from rules in the database.

**Architecture:** DocTypes `SEO Settings` (meta defaults only) and `SEO Rule`. A new module `website_rigpl/seo/meta.py` picks one rule for a page, renders the text templates in the #260 sandbox and applies the precedence. `item_page.update_website_context` calls it.

**Tech Stack:** Frappe 13.58, Jinja2 3.0.3, Python 3.8.

**Spec:** `docs/superpowers/specs/2026-11-28-website-seo-schema-design.md` (§5.1, §5.3, §9, D6, D8). Issue #261.

## Review Focus

1. Plain text in a template field, for example `Cutting tools in India`: it is output as text, not evaluated as an expression.
2. A template with a typo: that field keeps the lower-precedence value, one Error Log row, the page renders.
3. A template that renders empty: the lower-precedence value stays. No empty `<title>`.
4. A value with `"`, `<` or `>` in the title or canonical: no broken `<head>`.
5. A page with no document (`www` page, for example `/contact`): route rules and settings apply.

### Task 3: Rule match and precedence

**Files:** Create `website_rigpl/seo/meta.py`. Test `tests/test_seo_meta.py`.

**Interfaces:**
- Consumes: `render_text`, `sandbox.abs_url`, `sandbox.plain_text`, `context.build_variables`, `context.get_route`, `builder.BuildError`, `builder.log_errors`.
- Produces: `find_rule(doctype: Optional[str], route: str) -> Optional[Document]`; `build_meta(context, rule, errors: list) -> dict` with only the changed keys of `title`, `canonical`, `metatags`; `clear_rule_cache(path=None) -> None`.

Match: each condition that a rule has must match. The highest `priority` wins. At equal priority a rule with both conditions wins, then the first name.

Precedence per field: the first non-empty of document field, rule, settings. Settings has only title and description, plus `og:site_name` from `site_name`. A description gets `plain_text` and the limit, cut at a word. A title is not cut. `canonical` and `image` get `abs_url`. A new title sets `context.title`, `title`, `og:title`, `twitter:title`; a name tag from vanilla (`name`) takes the same value. A new description, image and canonical set their `og:` and `twitter:` tags (`og:url` and `url` for canonical). An image sets `twitter:card` to `summary_large_image` unless the rule sets a card. If `metatags.robots` already has `noindex`, the rule robots value is ignored. Website Route Meta is applied again last (route `""` is the Website Settings home page); its `title` also sets `context.title`. The input `context.metatags` is not mutated.

- [ ] Tests (one each): `test_priority_wins`, `test_doctype_and_route_must_both_match`, `test_disabled_rule_is_ignored`, `test_rule_beats_settings`, `test_document_field_beats_rule`, `test_route_meta_beats_all`, `test_no_values_changes_nothing` (result `{}`), `test_empty_render_keeps_lower_value`, `test_bad_template_keeps_lower_value_and_collects_error`, `test_description_loses_html_and_gets_limit` (length `<= 160`), `test_noindex_stays`, `test_canonical_is_encoded` (a `"` becomes `%22`), `test_site_name_replaces_erpnext`, `test_page_without_document`.
